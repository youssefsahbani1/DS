# Gestion des tâches (Python)

Application console simple de gestion de tâches quotidiennes, réalisée dans le cadre du module « Outils collaboratifs avec Git / GitHub » (Licence 1, S1).

## Fonctionnalités

- **1 – Ajouter une tâche** : demande un titre (refuse un titre vide).
- **2 – Afficher les tâches** : liste les tâches avec leur numéro (message si la liste est vide).
- **3 – Rechercher une tâche** : affiche les tâches dont le titre contient un mot-clé.
- **0 – Quitter** : ferme le programme ; toute autre option affiche un message d'erreur.

## Étapes réalisées

1. Création du dossier du projet dans VS Code et écriture de `main.py`.
2. Test du programme avec « Run Python File ».
3. Initialisation de Git et création de plusieurs commits.
4. Création du dépôt GitHub, liaison avec `origin` et premier `git push`.
5. Amélioration du code, nouveau commit et `git push`.

## Exécution

Ouvrir `main.py` dans VS Code, puis cliquer sur le bouton **« Run Python File »** (triangle en haut à droite).
